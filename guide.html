LA PREMIÈRE DÉCOUVERTE · LA MÉMOIRE

Une machine.
Des petits tiroirs.

Pour suivre une consigne, l’Apple‑1 doit d’abord la retrouver. Il utilise une mémoire : imagine une grande armoire à tiroirs numérotés.

···
$0300A9
$0301C1
$030220
···

Chaque case est un petit tiroir. Les nombres ci-dessus sont écrits en hexadécimal.

01 / MÉMOIRE

Chaque tiroir a un numéro.

Ce numéro s’appelle son adresse. Grâce à elle, la machine retrouve ce qu’elle cherche.

02 / PROCESSEUR

Il suit les consignes.

Le processeur lit les instructions et les réalise, une à la fois, comme les étapes d’une recette.

03 / ÉCRAN

Un nombre peut devenir une lettre.

La machine envoie un code au terminal pour lui demander d’afficher un caractère.

Pourquoi y a-t-il des lettres dans les nombres ?

L’ordinateur utilise parfois une écriture appelée hexadécimal. Elle utilise les chiffres de 0 à 9 et les lettres de A à F. Le signe $ indique qu’un nombre est écrit de cette façon. Tu n’as pas besoin de tout retenir pour jouer.

Un tiroir numéroté $0300 : est-ce une lettre ou une adresse ?

C’est une adresse : elle indique où trouver le tiroir dans la mémoire.

Pour les curieux · Voir les consignes en code+

Dans ce petit exemple, le processeur prépare le code d’une lettre, puis demande à ECHO de l’afficher.

$0300 A9 C1 LDA #$C1 $0302 20 EF FF JSR $FFEF

C1 est le code utilisé ici pour la lettre A. Dans le laboratoire, l’appel à ECHO est simplifié.
